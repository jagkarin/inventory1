
Warehouse Management System (WMS)

Features

1.User Profile Management: Edit user profile information.
2.Dashboard: View overall borrowing and returning activities.
3.Borrowing Equipment: Request to borrow office equipment.
4.Product Issuance: Request to borrow products for sale.
5.Adding Items: Add new products or equipment to the inventory.
6.Item Status Tracking: View the status of borrowed products and equipment.
7.Returning Equipment: Return borrowed equipment and update the status.

Installation

Backend (C# .NET 8)

Frontend (React.js)

Technologies Used

* React.js
* C# .NET 8
* Entity Framework Core
* MySQL Server
* Boostrap 5
* SweetAlert2
